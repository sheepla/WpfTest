# WpfInspector ロードマップ

## 現在地

現行実装は、プロセス選択、WPF 判定、自己プロセス直接走査、外部プロセス注入走査、ランタイム情報を使った PDB 再選択、Portable PDB 解析までを含む現行 MVP に到達している。

## 完了済み

### Phase 1: 基盤整備

- ソリューション作成
- Git 初期化
- `Core` / `App` / `Tests` 分割
- 仕様と実行フローの明文化

### Phase 2: 現行 MVP

- 実行中プロセス一覧
- プロセス詳細表示
- WPF 判定
- CodeView ベースの初期 PDB 候補解決
- apphost を考慮した初期解析対象の補正
- Portable PDB 解析
- 自己プロセス直接走査
- `NativeBootstrap + TestHelper` 注入による外部 WPF UI 走査
- ランタイムアセンブリ候補を使った PDB 解析対象の再決定
- UI ツリー表示
- 単体テストと UI テストの基盤整備

## 直近の改善候補

### Phase 3: 安定化

- UI テストを現行画面構成に合わせて整理する
- 起動中アプリによるビルド成果物ロックを避けるテスト手順を整える
- 注入失敗時のステータス表示と診断ログ導線を整理する
- NativeBootstrap のビルド前提と配布手順を明確化する

## 方針メモ

- 専用モジュール一覧 UI、PDB エクスポート、フィルタ永続化、セッション比較、署名済み解析アダプタなど、現行実装に存在しない項目はロードマップから外す
- 追加実装は、まず現行の自己走査 / 注入走査 / PDB 解析フローを壊さないことを優先する
