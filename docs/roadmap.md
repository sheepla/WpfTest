# WpfInspector ロードマップ

## Phase 1: 基盤整備

- ソリューション作成
- Git 初期化
- Core / App / Tests 分割
- 仕様と実行フローの明文化

## Phase 2: 解析 MVP

- 実行中プロセス一覧
- プロセス詳細表示
- モジュール列挙
- CodeView ベースのメインモジュール PDB 候補解決
- Portable PDB 解析
- 検査ペイロード注入による WPF UI 走査

## Phase 3: 検証強化

- PDB 解析結果のエクスポート
- フィルタ条件の保存
- 大規模 PDB 向けの非同期読み込み最適化
- テストケース拡充

## Phase 4: 拡張ポイント

- 注入失敗時の自動再試行と診断ログ拡充
- 署名済み解析アダプタのロード
- セッション記録と比較機能
- CI でのビルド・テスト自動化
