# WpfInspector 仕様

## 目的

WPF アプリケーションを対象に、実行中プロセスの状態確認、ランタイム UI 走査、走査結果を用いた PDB 解析を 1 つの WPF ツールで実施できるようにする。外部プロセスには DLL インジェクションを使い、WpfInspector 自身を選択した場合は自己プロセスを直接走査する。

## 対象ユースケース

1. 実行中のプロセス一覧から対象 WPF を選択して、PID・タイトル・実行ファイルパスを確認する
2. WpfInspector 自身を選択し、自己プロセスに対して UI 走査と PDB 解析を実行する
3. 対象プロセスにロードされている DLL/EXE を確認し、メインモジュールと PDB 候補を把握する
4. 同じ WPF プロセスを走査し、ウィンドウ一覧・ビジュアルツリー・ランタイムアセンブリ候補を収集する
5. 走査結果から実際に使われているアセンブリを優先して選び、その PDB を解析する

## 機能要件

### 1. プロセス一覧

- 実行中プロセスを名前順で一覧表示する
- プロセス名、PID、ウィンドウタイトル、応答状態を表示する
- 自己プロセスであるかどうかを表示する
- フィルタ文字列で絞り込みできる

### 2. プロセス詳細

- 選択プロセスの実行ファイルパスを表示する
- 起動時刻、ワーキングセット、モジュール数を表示する
- 取得失敗時は注意メッセージを表示する

### 3. モジュール解析

- ロード済みモジュールのパス、ベースアドレス、メモリサイズを表示する
- PE の Debug Directory から CodeView 情報を読み取る
- 同一ディレクトリ上の PDB 候補パスを解決する
- Embedded Portable PDB の有無を表示する

### 4. PDB 解析

- 選択中 WPF のメインモジュール PDB を初期候補として自動入力する
- UI 走査後は、ランタイムで実際に使われているアセンブリを優先して解析対象を再決定する
- 必要に応じて `.pdb` / `.dll` / `.exe` を手動指定できる
- Portable PDB を解析し、以下を表示する
  - 文書一覧
  - メソッド一覧
  - メソッドごとのシーケンスポイント数
  - 可視シーケンスポイント数

### 5. WPF UI 走査

- WPF 判定済みの選択プロセスに対して一括解析を実行できる
- 一括解析では、先にランタイム走査を実行し、その後に走査結果から PDB 解析対象を決定する
- 外部プロセスでは検査ペイロードを注入し、WpfInspector 自身を選択した場合はアプリ内で直接走査する
- 走査後は以下を表示する
  - WPF バージョン
  - Dispatcher 状態
  - ウィンドウ一覧
  - 選択ウィンドウのビジュアルツリー
  - ランタイムで使用中のアセンブリ候補
- UI 走査が完了した場合、PDB 解析は可能な限り継続する

## 非機能要件

- .NET 9 / WPF ベース
- コアロジックは UI から分離し、xUnit でテスト可能にする
- 管理者権限がなくても取得できる情報を優先する
- Protected Process 等の失敗は例外で終了させず、UI に通知する

## セキュリティ境界

- DLL インジェクション対象は、UI 上でユーザーが選択した外部 WPF プロセスに限定する
- 注入する DLL はアプリに同梱した `WpfInspector.NativeBootstrap.dll` と `WpfInspector.InspectionPayload.dll` を前提とする
- WpfInspector 自身を選択した場合は注入を行わず、同等の走査ロジックをアプリ内で実行する
- 権限不足、アーキテクチャ不一致、PDB 未検出などの失敗は例外で終了させず、UI に通知する

## アーキテクチャ

- `WpfInspector.App`
  - 画面表示
  - ユーザー操作
  - ViewModel
  - UI 走査と PDB 解析対象決定の実行オーケストレーション
- `WpfInspector.Core`
  - プロセス列挙
  - モジュールと PE シンボル情報の読み取り
  - Portable PDB 解析
- `WpfInspector.Injector`
  - Native DLL 注入
- `WpfInspector.InspectionPayload`
  - 注入後、または自己プロセス直接実行時の WPF UI 走査
