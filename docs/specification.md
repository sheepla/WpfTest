# WpfInspector 仕様

## 目的

WPF アプリケーションを対象に、実行中プロセスの状態確認、ロード済みモジュール調査、PDB 解析を 1 つの WPF ツールで実施できるようにする。

## 対象ユースケース

1. 実行中の WPF プロセスを選択して、PID・タイトル・実行ファイルパスを確認する
2. 対象プロセスにロードされている DLL/EXE を確認し、PDB 候補を把握する
3. Portable PDB を指定し、ソース文書・メソッド・シーケンスポイントを解析する
4. モジュール選択から関連 PDB を自動入力し、即座に解析する

## 機能要件

### 1. プロセス一覧

- 実行中プロセスを名前順で一覧表示する
- プロセス名、PID、ウィンドウタイトル、応答状態を表示する
- フィルタ文字列で絞り込みできる

### 2. プロセス詳細

- 選択プロセスの実行ファイルパスを表示する
- 起動時刻、ワーキングセット、モジュール数を表示する
- 取得失敗時は注意メッセージを表示する

### 3. モジュール解析

- ロード済みモジュールのパス、ベースアドレス、メモリサイズを表示する
- PE の Debug Directory から CodeView 情報を読み取る
- 同一ディレクトリ上の PDB 候補パスを解決する
- Embedded Portable PDB の有無を表示する

### 4. PDB 解析

- `.pdb` ファイルを選択できる
- 必要に応じて `.dll` または `.exe` を指定し、メソッド名を解決する
- Portable PDB を解析し、以下を表示する
  - 文書一覧
  - メソッド一覧
  - メソッドごとのシーケンスポイント数
  - 可視シーケンスポイント数

## 非機能要件

- .NET 9 / WPF ベース
- コアロジックは UI から分離し、xUnit でテスト可能にする
- 管理者権限がなくても取得できる情報を優先する
- Protected Process 等の失敗は例外で終了させず、UI に通知する

## セキュリティ境界

- 任意プロセスに対する DLL インジェクションは実装しない
- 将来的な拡張は、署名済みヘルパー DLL を起動時に読み込む方式や、診断 API による安全なアタッチ方式を前提とする
- 本バージョンは、PE/PDB の解析とプロセス情報の観測に限定する

## アーキテクチャ

- `WpfInspector.App`
  - 画面表示
  - ユーザー操作
  - ViewModel
- `WpfInspector.Core`
  - プロセス列挙
  - モジュールと PE シンボル情報の読み取り
  - Portable PDB 解析
